# mainboard PCB
this repo contains the pcb file for the velion mainboard.
schematic + layout in PDF are available in the export folder
this board offer a control pannel with physical button for the use to control the seat + hand heater, a defroster, lightning (fog + interrior + warning), selenoid for a trunk latch, speed and mapping button.
it can drive a few load like the said heater and defroster, an aux load for music system, a USB-C port, rearview mirror with DRL and blinker
it also has input for a PAS, two brake switch and a seat sensor
it has an accelerometer for traction control
